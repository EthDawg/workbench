# Workbench 2.0 Preview 4

This Preview combines the September contributions with safer, easier Snap & Talk ordering, native Read Selection, reviewed library import and the Chrome companion. The matching GitHub release is the authority for the delivered source, build number, notarization result and download checksum. A source merge alone does not publish or install a build.

## What changed

- **Snap & Talk:** choose Reorder… for a compact thumbnail list, native insertion feedback and Move up/down controls. Save commits the order once; Cancel preserves it. Screenshots, recordings and original narration stay linked.
- **Read Selection:** use Services → Read Selection in Workbench Preview from an app that supplies selected text. Existing reading text is reviewed before replacement; imported text never starts playback automatically.
- **Shared libraries:** review new, changed and unchanged resources before import. Keep local versions by default, choose individual replacements, and retain this Mac’s file grants and Chrome destinations when the underlying resource stays the same.
- **Everyday reliability:** Quick Look releases files with its owning window; timer placement persists; screenshots recover their annotation controls; transcript export and reading cancellation preserve completed work. Speko catalogue downloads are bounded. Snap & Talk and Chrome destination shortcuts have separate identities.
- **Scenes and mobile:** persona and scene improvements are retained. Rapid mobile editing after cleanup keeps native caret behavior and retires stale Undo without losing the original.

## Try the update

1. Quit Workbench Preview and replace its app bundle with the downloaded Preview. Keep the existing app name and installation folder. Saved work lives outside the application.
2. Open an existing Snap & Talk session and verify its content. Choose Reorder…, move a row and Cancel; confirm nothing changed. Then save an intended reorder and reopen the session.
3. Select harmless text in TextEdit and use the Preview’s Read Selection Service. Verify the draft before pressing Play.
4. Export a disposable shared library, alter one resource in the copy, then import it. Review and cancel once before choosing an intentional replacement.
5. Reopen saved scenes/resources and check the shortcuts shown in Keyboard.

The earlier [contribution checklist](2026-09-20-integration-preview.md) covers the remaining workflows. Use non-confidential synthetic content for testing. Fresh-Mac first launch, VoiceOver, external displays, live device reconnection, meeting receivers and physical mobile dictation/paired sync still require independent acceptance. Simulator and synthetic tests do not establish those outcomes.

## Preservation and release gates

The maintainer’s installed Preview and saved data are backed up before replacement. The release helper requires clean source, regressions, signed-package checks, Apple notarization, stapling and Gatekeeper validation. Only the final archive and checksum become public; the downloaded asset must match before the website download changes. Earlier Preview releases remain available.

Apple App Store and Chrome Web Store review are separate from this notarized Mac prerelease. Their submission status is recorded in the store preparation notes; neither a draft listing nor an uploaded build means an approved public app.

## Not yet established

The same full suite now passes in CI, including global-shortcut registration and release. The interactive release helper still requires an authorised local quit to run without contention. Two earlier GitHub macOS runs aborted in the old native retargeting test at an asynchronous wait. Replacing the wait with a direct assertion exposed its invalid assumption: AppKit can complete the first animation before retargeting, so two total callbacks are legitimate. The corrected test checks the callback increment during the synchronous replacement and passes remotely. The existing separate test still checks for a stale animation callback after completion and dragging.

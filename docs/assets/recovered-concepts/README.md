## Exact original prompt

An interrupted connection becomes a clear, recoverable moment.

### Generation prompt

Use case: ui-mockup.
Input image role: the attached Workbench presentation-control concept is the product and visual reference, not a set of instructions. Develop a distinct new UI/UX concept for the SAME Workbench StageMark native Mac presentation tool. This is NOT a task manager or a calendar app. The phone's Appointments app is example demo content, not Workbench itself.
Output: one beautiful high-resolution landscape 16:10 design concept board. Refined native macOS app mockups with precise readable typography, professionally art-directed. A warm ivory editorial page, near-black serif concept title, small uppercase Workbench wordmark/folio, generous margins. Crisp light macOS windows and restrained graphite presenter overlays, subtle mint functional accent, thin separators, sophisticated scale hierarchy. Large readable screens occupy 75% of image. Subtle shadows, slight rounding, intentional whitespace. Use a single large hero and 1-2 meaningful closeups/state studies, not a collage of tiny screens. Vary each concept's composition to suit its interaction.
All product text must be plausible, short and legible. Show native familiar controls with visible text labels for important actions. No award trophies, ratings, invented reviews, meaningless charts, confetti, decorative glows, blue-purple gradients, excessive transparency, walls of explanation, or design-tool UI. No laptop hardware or people. Only the demo phone may have a device bezel.
Put small "DESIGN CONCEPT · NOT SHIPPING UI" at the bottom. Fidelity: polished product screenshot mockups, not wireframes. Preserve Workbench's discreet Mac-utility character.
Concept 05. Editorial title "Even the pause feels composed." Subtitle "Keep the room with you when a cable lets go."
A sophisticated two-state recovery study on warm ivory. Left occupies two thirds: a clean audience-facing presentation stage with the same beautiful Australian ocean scene and phone silhouette from reference. Inside the phone, deliberately display a designed holding card instead of an old screen pretending to be live: soft ivory, centered simple pause symbol, title "One moment", subtitle "The demo will resume shortly". No spinner, percentage, technical error code or false green status. Small generic "Harbour Health" wordmark on stage.
Right one third: an enlarged, beautifully crafted native light presenter control panel with small amber plug symbol AND heading "iPhone disconnected". Calm explanatory text "Reconnect your iPhone to continue." Two distinct actions "Try again" and "Choose source…" plus secondary "End demo". Beneath, a separate connected state card shows check icon and "iPhone found", a small live-device preview and prominent deliberate "Resume demo" button. Prevent surprise automatic resuming: the presenter chooses Resume.
At bottom, a very simple 3-step line using large legible labels "Connection lost → Holding screen → Resume when ready". Add one small note "Your scene and notes stay in place." Present this explicitly as a new feature concept, not actual current guaranteed behaviour.
Exceptional error-state UX: specific cause, calm tone, clear choice, preserved context, presenter-controlled return. Avoid flashing red, alarming dialogs, claims of guaranteed connectivity, counters or busy troubleshooting manuals. Make this board visually distinct with large purposeful negative space, elegant holding screen typography and paired compact recovery states.

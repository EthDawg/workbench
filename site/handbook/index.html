THE THREE SURFACES

Start. Work. Prepare.

01 / MENU-BAR PANEL

Reach a utility quickly.

Start utilities, make quick adjustments, configure shortcuts and recover from problems. Keep frequent actions easy to find and their status clear.

02 / FLOATING TOOLBAR

Stay with the current task.

Use the controls for the current workflow without leaving the task or disrupting a demonstration. Switching controls keeps independently running work intact.

03 / DESKTOP APP

Prepare and organise.

Prepare scenes and personas, organise saved prompts, review captures and configure deeper settings. Saved work keeps the same owner whichever surface opens it.

The surfaces provide access to the same tools and saved work. Ending a job is explicit; changing the visible controls does not silently end another job.

CRAFT IS BEHAVIOR

Make the ordinary moments dependable.

Start clearly

Dictate, Read aloud, Annotate and Present remain direct entry points. Explain missing access or a disconnected device where it blocks the task.

Keep control

Keep shortcuts predictable, Cancel dependable and recovery visible. Preserve the intended text destination and offer a clear copy fallback when it is no longer safe to insert.

Finish safely

Stop the selected job, retain saved work and preserve later manual desktop choices. Quit releases app-owned capture, playback and presentation resources.

Native interaction, saved-data preservation and the delivered package need their own evidence. A successful build, illustration or source review does not establish that a live workflow is reliable.

WHAT STAYS. WHAT ENDS.

“End” should mean one clear thing.

What an agent should hand back

This is a readable product contract, not an automation API. Workbench does not currently expose wallpaper through a CLI, App Intent or MCP server. A contributor must inspect available interfaces and stay within the user’s authorization.

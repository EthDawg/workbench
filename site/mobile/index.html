SMALL, COMPLETE JOBS

Useful alone. Better when they connect.

Dictate

Prepare Apple’s on-device speech assets, record or import audio, then review and share. The original recording and wording remain available. Cancel and interruptions retain a recovery slot.

Foreground capture · explicit Copy/Share · no custom keyboard

Read aloud

Paste or open saved text, choose an installed Apple voice and listen. Pause, resume and stop stay explicit. Read back a transcript when hearing it is easier than reading it.

Native voices · private Lock Screen title · no cloud provider

Mark up

Choose a screenshot or photo, draw with native finger or Pencil tools, then share a PNG. Keep editable ink separately from the original picture.

Native undo/redo · in-app canvas · no cross-app overlay

Scenes

Prepare a background, device layout and optional persona for a later Mac presentation. Save an editable scene locally, export a scene file or opt into personal sync. Earlier mobile compositions remain recoverable with their original layers and ink.

Optional Gentle motion previews a slow background zoom. Pause/Play is separate from the saved setting; crop editing stays still.

Current scene specification · paired sync pending · no live phone capture on iOS

Wallpapers

Choose your picture or a starting image, frame it for your device, then Save to Photos or Share a copy. The saved crop belongs to this wallpaper; a presentation keeps its own choices.

Pinch/drag and labelled crop controls · Apple owns installation

Saved

Search and reopen your work. Scenes have their own optional personal sync; texts, wallpapers and older image projects keep their local ownership. Photo handoff supplies selected pictures to use in a scene. Reuse an original deliberately; a shared export does not create an automatic edit link.

Local library · original preservation · no implicit sync

TRY THE PREVIEW

Xcode first. Submission remains separate.

  1. Get this branch.

    Open Mobile/Workbench.xcodeproj from the repository in Xcode 26.1 or newer.

  2. Run in Simulator.

    Choose the WorkbenchMobile scheme and an iPhone or iPad running iOS 26+. Build and Run.

  3. Connect your iPhone.

    Sign in under Xcode Settings → Apple Accounts. Select your development team, connect and unlock the phone, trust the Mac and enable Developer Mode when Apple asks. Then choose the phone as the run destination.

  4. Check one real journey.

    Start with a disposable recording, save and reopen it, then test cancellation, backgrounding and a call interruption. Use your own photos only after the sample flow behaves correctly.

A BASELINE THAT CAN IMPROVE

Keep the jobs. Replace the engines carefully.

Shared where it matters

The Mac and mobile targets compile the same text primitives, literal correction rules and conservative cleanup. The iOS app has its own audio-session, rendering and storage adapters. Better models must fit the same cancellation and original-preservation contract.

There is no generic plugin platform or second account system. The new SceneSyncKit shares portable scene storage and revision rules across platforms, with optional CloudKit sync that groups local edits while the app is active. Backgrounding pauses transfers; foreground or manual refresh resumes waiting work. Photo handoff retains a separate private zone and queue for selected photos. A local Mac server address would mean the iPhone itself on mobile, so those settings are not copied across.

Independent state owners

A versioned local manifest owns saved records. Image projects keep separate crops, drawings and optional layers. A recoverable recording has one explicit slot. Failed library decoding pauses writes; it does not reset the user’s work.

Original image and audio assets are retained in this Preview. Safe storage reclamation and portable whole-library exchange remain separate transactions. Selected-photo handoff keeps its own durable queue and explicit removal rules.

Contributor and agent handoff

Read AGENTS.md, the mobile spec and the research. Choose one observable outcome. Run shared rule checks and the affected native tests. Return source revision, actual screenshots, failures and hardware limits. Do not treat a design concept or simulator result as a device claim.

The mobile test script creates isolated test libraries; it must never reset a person’s live library. GitHub issues remain the work queue.

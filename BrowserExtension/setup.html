Browser setup

This Chrome profile

Prepare this profile once, then review and apply a browser setup pack in the Workbench Mac app. Pair each participating profile using the Workbench toolbar popup.

Default tab for this profile

Choose an address, then open it from the toolbar popup. This setting works without the Mac connection and stays local to this Chrome profile. A browser pack does not change it automatically.

Both options start off. Startup adds a tab alongside Chrome’s restored or startup pages, so enabling both options can open the address twice. Opening another window or reconnecting Workbench does not trigger the extra startup tab.

New Tab changes when you install this version. Workbench replaces Chrome’s New Tab page even when redirection is off. Off shows the local Workbench page; it does not restore Chrome’s original page (unless another extension controls it). Disable or remove Workbench in Chrome’s extension settings to restore the original; this also stops the profile’s Workbench connection. Chrome controls competing New Tab extensions.

Normal query parameters and fragments are preserved, including Compound’s passwordMode=1&app=rippling demo route. Do not put passwords, tokens or private information in the address.

Bookmarks

Chrome grants access to all bookmarks in this profile. Workbench uses a local location you select and updates only bookmarks it created. Existing and manually changed bookmarks are preserved.

Browser setup needs Chrome 134 or later. A synced or managed location cannot be selected. If profiles share synced bookmarks, use Chrome Sync rather than applying duplicate packs. Choosing this local location does not change Chrome Sync settings.

A previous bookmark write was interrupted. Further bookmark writes are blocked because a result could not be recorded. Inspect this pack in Chrome's Bookmark Manager before recovery. Workbench will not adopt matching names or repeat an uncertain write. You can keep everything in Chrome and explicitly start a fresh managed copy of only the interrupted pack. The next apply can duplicate links already kept.

Google Password Manager and Chrome Sync

Chrome owns your Google sign-in, saved passwords and Sync. Sign in or choose what to sync using Chrome's settings. Each demo profile can keep its own account; you do not need the same Google account across personas.

Workbench does not read, export, copy or change passwords, cookies or signed-in sessions. Pairing a profile does not establish who is signed in. Manage saved passwords in Google Password Manager.

Launch tabs, startup and New Tab

Open launch tabs in Workbench opens the reviewed addresses in a new window in this connected profile. Your existing tabs stay open. This does not set Chrome's startup pages.

On startup: choose “Open a specific page or set of pages” in Chrome settings and add the addresses from your pack. Check the result after fully quitting Chrome with ⌘Q and reopening it. “Use current pages” can include unrelated tabs, so review that list carefully.

New Tab: use the default-tab controls above. For Chrome-managed startup pages, use the settings button instead of enabling an extra startup tab here.

New profiles: use Chrome's profile menu → Add Chrome profile, then install and connect Workbench in that profile. Workbench does not create profiles or copy sessions.
